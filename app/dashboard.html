API Usage

Use LLM API Bridge with OpenAI-compatible clients.

Endpoint

POST http://AGDEV_IP:9920/v1/chat/completions

Provider Selection

Set the model field to one of: chatgpt, claude, gemini, deepseek.

Each provider must be logged in via the dashboard first.

Example: curl

curl -X POST http://AGDEV_IP:9920/v1/chat/completions -H "Content-Type: application/json" -d '{model:chatgpt,messages:[{role:user,content:Hello}],stream:false}'

Example: streaming

curl -X POST http://AGDEV_IP:9920/v1/chat/completions -H "Content-Type: application/json" -d '{model:chatgpt,messages:[{role:user,content:Hello}],stream:true}'

OpenAI-compatible

This API uses the same format as OpenAI. Use it with any tool that supports OpenAI API by setting the base URL to http://AGDEV_IP:9920/v1.

Models endpoint

GET http://AGDEV_IP:9920/v1/models returns list of connected providers.
